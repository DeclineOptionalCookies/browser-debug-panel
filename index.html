browser-debug-panel

Lightweight zero-dependency debug overlay for the browser.

Press Ctrl + Shift + D (or ⌘ + Shift + D on Mac) to open the panel.

Or click the button below:

What you get

  • Live FPS + frame time
  • Viewport & device info
  • localStorage / sessionStorage inspector + editor
  • Console capture
  • Quick actions (hard reload, clear storage, copy URL…)
